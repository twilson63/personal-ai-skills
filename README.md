# personal-ai-skills

Personal collection of agent skills, published for [`npx skills`](https://github.com/vercel-labs/skills) and indexed on [skills.sh](https://skills.sh).

## Install

```bash
npx skills add twilson63/personal-ai-skills --skill health-coach-creator
```

## Skills

| Skill | What it does |
| --- | --- |
| [health-coach-creator](skills/health-coach-creator/SKILL.md) | Interview a user to capture health data, build a Coach agent, then run morning/evening check-ins and weekly reviews on a metabolic-reset protocol. |
